# TRPG 新手入门：DND 与 COC 的骰子机制对比

> 本文是 TRPGHelper 项目内置的科普演示文档，帮助刚接触跑团的玩家快速理解两大主流体系的基本判定逻辑。文中规则细节以你实际使用的规则书为准。

## 一句话概括

| 体系 | 核心骰子 | 成功判定方式 | 典型场景 |
| :-- | :-- | :-- | :-- |
| **DND 5e**（龙与地下城第五版） | d20 | 掷得越高越好，对比 DC（难度等级） | 战斗、法术、地下城探险 |
| **COC 7版**（克苏鲁的呼唤第七版） | d100（百分骰） | 掷得越低越好，不超过技能值 | 调查、理智、恐怖生存 |

**两个体系“成功”的方向完全相反**：DND 是“掷得高才成功”，COC 是“掷得低才成功”。混在一起是新手最常见的错误。

## DND 5e：d20 + 调整值 vs DC

- 几乎所有判定都是：**掷 d20 + 相关属性调整值（+ 熟练加值，若熟练）**，结果 ≥ DC 即成功。
- **DC 由谁定**：陷阱、环境由 DM 设定；法术的豁免 DC = 8 + 施法者熟练加值 + 施法关键属性调整值。
- **优势/劣势**：处境有利时掷 2 个 d20 取高（优势）；处境不利时掷 2 个 d20 取低（劣势）。多个优势/劣势并存时不叠加。
- **豁免**：法术或区域效果通常要求目标掷豁免（如**火球术要求敏捷豁免**，失败受 8d6 火焰伤害，成功减半为 4d6）。
- **伤害骰**：常见如 1d8（长剑单持）、2d6（巨剑）、8d6（火球术），加上固定调整值。

## COC 7版：d100 低于技能值

- 判定方式：**掷 d100，结果 ≤ 你的技能值即成功**。
- 难度分级：**常规成功**（≤ 技能值）、**困难成功**（≤ 技能值一半）、**极难成功**（≤ 技能值四分之一）、**大成功**（掷出 01）、**大失败**（掷出 100，或通常约定 ≥ 96 且高于技能值）。
- **奖励骰/惩罚骰**：处境有利/不利时，额外掷一个“十分位骰”（十位骰），取较好/较差的结果组成最终值。
- **理智检定（SAN Check）**：遭遇恐怖场景时掷 d100 ≤ 当前理智值。失败或成功都要扣 SAN（写法如 **0/1d6**：成功扣 0 点，失败扣 1d6 点）。SAN 掉到阈值以下会触发**临时疯狂**或**不定疯狂**。
- **战斗**：先掷命中（近战/射击类技能，d100 判定），命中后掷伤害骰并加**伤害加值（DB）**——DB 由力量+体型共同决定。

## 新手跑团行动建议

1. **告诉规则助手你的角色属性**：把职业、等级、关键属性调整值（DND）或关键技能值（COC）在对话里告诉它，判定时它可以直接帮你算。
2. **掷骰后回报结果**：例如“我掷了 14 + 敏捷 +2 = 16，DC 是 15”，规则助手能直接告诉你是否通过、该扣多少血。
3. **先问清楚体系**：同一个法术/概念在不同书里完全不同，提问时先说明“我用的是 DND 5e”或“COC 7版”，避免答案对不上版本。
